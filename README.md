# Шахматы в браузере

Классические шахматы, которые работают целиком на клиентской стороне: один файл HTML, два файла JS и таблица стилей. Ничего не скачивать и не устанавливать — откройте страницу и играйте. Работает офлайн и адаптирована под телефон.

## Возможности

- Полные правила: рокировка, взятие на проходе, превращение пешки, мат, пат, ничья по 50 ходам и троекратному повторению позиции.
- Режимы: двое игроков за одним устройством, а также игра против простого компьютера (минимакс с альфа-бета отсечением, три уровня силы).
- Подсветка доступных ходов, история ходов в шахматной нотации, отмена хода, новая партия.
- Сохранение партии в браузере (localStorage) — можно закрыть страницу и продолжить позже.
- Адаптивный интерфейс: корректно работает и на телефоне, и на компьютере.

## Как играть

Сайт публикуется через GitHub Pages. После включения Pages в настройках репозитория (Settings → Pages → Deploy from a branch → ветка `gh-pages`) игра откроется по адресу:

`https://vitaliysavchenko42-ui.github.io/browser-chess/`

Либо просто откройте `index.html` из ветки `gh-pages` локально в браузере.

## Структура проекта

```
index.html        — разметка страницы (ветка gh-pages)
css/style.css     — стили доски и интерфейса
js/rules.js       — шахматный движок: правила, генерация ходов, шах/мат/пат
js/ai.js          — компьютерный противник (минимакс + альфа-бета)
js/app.js         — интерфейс: доска, подсветка, панель управления, история
docs/SPEC.md      — техническое задание
js/rules.test.js  — автотесты движка (node, без зависимостей)
```

## Тесты

Автотесты движка запускаются локально без сборки и зависимостей:

```
node js/rules.test.js
```

## ТЗ и этапы разработки

Подробное техническое задание — в [docs/SPEC.md](docs/SPEC.md). Реализация велась поэтапно:

1. Каркас проекта и статичная доска.
2. Шахматный движок с полными правилами.
3. Игровой интерфейс.
4. Компьютерный противник и публикация.
