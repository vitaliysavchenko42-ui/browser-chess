# Шахматы в браузере

Классические шахматы целиком на клиентской стороне: без установки и без сервера. Работает офлайн, адаптирована под телефон.

## Возможности

- **Кампания из 10 уровней**: от «Новичка» до «Чемпиона» — сила компьютера растёт от уровня к уровню, прогресс сохраняется в браузере. Уровень открывается после победы над предыдущим.
- Игра вдвоём на одном устройстве.
- Полные правила: рокировка, взятие на проходе, превращение пешки, мат, пат, ничья по 50 ходов, троекратному повторению и недостатку материала.
- **Векторные фигуры (SVG)** — идеально ровно по центру клеток на любом устройстве и шрифте.
- **Анимация хода**: фигура плавно переезжает из клетки в клетку — ход компьютера хорошо виден.
- Подсветка доступных ходов, история в шахматной нотации, отмена хода, автосохранение партии.

## Структура проекта

```
index.html        — разметка (карта уровней + экран партии)
css/style.css     — стили доски, карты, анимации
js/rules.js       — шахматный движок: правила, генерация ходов, шах/мат/пат
js/ai.js          — компьютерный противник (минимакс + альфа-бета, 10 уровней силы)
js/app.js         — интерфейс: карта уровней, доска, анимация, прогресс кампании
docs/SPEC.md      — техническое задание
js/rules.test.js  — автотесты движка (node, без зависимостей)
```

## Тесты

Автотесты движка запускаются локально без сборки и зависимостей:

```
node js/rules.test.js
```
